# 📱 TechRatunek Lubartów

Responsywna strona internetowa wymyślonego serwisu napraw telefonów w Lubartowie. Prezentuje ofertę usług, orientacyjny cennik oraz formularz zgłoszenia naprawy z walidacją.

## ✨ Funkcjonalności

- **Menu mobilne**
- **Tryb jasny / ciemny**
- **Zależne listy w formularzu**
- **Walidacja formularza**
- **Płynne przewijanie**

## 🛠️ Wykorzystane technologie

| Technologia | Zastosowanie |
|---|---|
| **HTML5** | semantyczna struktura strony (`header`, `nav`, `main`, `section`, `article`, `footer`) |
| **CSS3** | Flexbox, zmienne CSS, media queries, efekty `:hover`, tryb ciemny |
| **JavaScript** | menu, motyw, zależne listy, walidacja formularza |
| **GitHub Pages** | publikacja strony |

## 📁 Struktura projektu
